# Welcome to FirstDevJob

FirstDevJob is a platform designed to help aspiring developers find their first job in tech. We curate entry-level positions, internships, and junior roles to make your job search easier.

## What You'll Find Here

This documentation covers:

- **User Guide** - How to use the platform effectively
- **Architecture** - Technical overview of how the system works
- **Technical Reference** - Detailed documentation for contributors
- **API Reference** - Convex functions and data models

## Tech Stack

FirstDevJob is built with modern technologies:

| Technology | Purpose |
|------------|---------|
| Next.js | React framework for the frontend |
| Convex | Real-time backend and database |
| Clerk | Authentication and user management |
| Tailwind CSS | Styling and design system |
