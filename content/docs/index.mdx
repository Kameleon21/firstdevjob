FirstDevJob is a job board for internships, graduate roles and other early-career developer jobs. Anyone can browse the listings; signing in adds bookmarking, an application tracker and optional email alerts when a matching job is approved. Submitted jobs are reviewed by a moderator before they appear. These docs cover both sides of that: how to use the site, and how it is built.

The app is a Next.js 16 frontend on Vercel talking directly to a Convex backend, with Clerk for authentication and Resend for email. Every page in the technical sections is written against the code in this repository — if a page disagrees with the source, the source is right and the page is a bug.

## Tech stack

| Technology | Purpose |
|---|---|
| Next.js 16 (App Router) | Frontend, routing, server rendering, the docs site |
| React 19 | UI runtime |
| Convex | Database, backend functions, real-time subscriptions, crons |
| Clerk | Authentication, sessions, OAuth, JWTs verified by Convex |
| Resend | Transactional email, sent from Convex via `@convex-dev/resend` |
| Tailwind CSS 4 | Styling and design tokens |
| Fumadocs | These docs: MDX content, layout and search |
| Bun | Package manager and script runner, pinned to 1.4.2 |
| TypeScript | Types across frontend and backend, including generated Convex types |

Exact versions live in [Tech Stack](/docs/architecture/tech-stack) and in `package.json`.

## Keyboard shortcuts

These work anywhere in the documentation site.

| Shortcut | Action |
|---|---|
| `Cmd` + `K` / `Ctrl` + `K` | Open search |
| `Cmd` + `B` / `Ctrl` + `B` | Toggle the sidebar |

On screens 768px and wider, `Cmd`/`Ctrl` + `B` collapses and expands the sidebar column; below that it opens and closes the sidebar drawer. Both shortcuts are ignored while you are typing in a text field, so they never swallow a keystroke mid-search.

<Callout type="info">
Search indexes page titles and headings across every page in this site, so searching for a function name such as `listApprovedJobs` or a table name such as `trackedApplications` is usually faster than navigating the sidebar.
</Callout>
