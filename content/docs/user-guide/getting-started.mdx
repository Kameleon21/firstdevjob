# Getting Started

Welcome to FirstDevJob! This guide will help you get set up and start your job search.

## Creating an Account

1. Click the **Sign Up** button in the header
2. Choose to sign up with GitHub or email
3. Complete your profile information

## Exploring Jobs

Once signed in, you can:

- Browse the job listings on the homepage
- Bookmark jobs you're interested in
- Track your application progress
