# Tracking Applications

Stay organized with the built-in application tracker.

## Application States

Track your applications through different stages:

| Status | Description |
|--------|-------------|
| Bookmarked | Saved for later |
| Applied | Application submitted |
| Interview | Interview scheduled |
| Offer | Received an offer |
| Rejected | Application not selected |

## Managing Applications

1. Open a bookmarked job
2. Click "Track Application"
3. Update the status as your application progresses
4. Add notes for your reference

## Tips

- Update statuses promptly to keep your tracker accurate
- Use notes to record interview details and follow-up dates
- Review your tracker regularly to follow up on applications
