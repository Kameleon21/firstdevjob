# Posting Jobs

Help the community by sharing entry-level job opportunities.

## Submission Process

1. Click **Submit Job** in the navigation
2. Fill out the job details form
3. Submit for review

## Required Information

| Field | Description |
|-------|-------------|
| Job Title | The position title |
| Company | Company name |
| Position Level | Intern, Graduate, or Early Career |
| Location | City, state, or "Remote" |
| Job Posting URL | Link to application page |
| Tags | Relevant technologies |

## Review Process

All job submissions are reviewed before appearing on the site:

- Jobs are reviewed by moderators
- Approved jobs appear in the listings

## Security Checks

The form is validated server-side before a job is saved:

- Required fields are normalized and validated
- URLs must be public `http`/`https` links
- URLs with local/private-network hosts are rejected
- Rate limits apply to reduce submission abuse

## Guidelines

- Only post entry-level or junior positions
- Ensure the job is currently accepting applications
- Provide accurate company information
